# Mitra MVP Implementation Plan

> **For agentic workers:** This plan is executed by **parallel subagents** (workflow orchestration, GLM-5.3-Flash) on the module sets defined below, then integrated by the orchestrator. Steps use checkbox (`- [ ]`) syntax for tracking. Shared interfaces are frozen in `app/src/shared/` by Phase 0 — subagents must consume them, not reinvent them.

**Goal:** Ship a demo-able Electron voice assistant: hotkey-summoned orb overlay, Bolna-powered voice sessions (Hindi/Hinglish/English), permission-gated tools (Notion, app launcher, opencode), persona customization — fully functional in mock mode with zero API keys.

**Architecture:** Electron (main = windows + local bridge HTTP server + tool execution; renderer = React). Voice brain behind a `VoiceProvider` interface — `BolnaProvider` (`@bolna/web-call`, WebRTC in renderer, sessions minted by the bridge) with `MockProvider` fallback. Persona = R3F shader orb (default) or VRM avatar, audio-reactive via Web Audio `AnalyserNode`.

**Tech Stack:** Electron 39, electron-vite, React 19, TypeScript (strict), Vite, Tailwind CSS v4, three + @react-three/fiber v9 + drei, @react-three/postprocessing, @pixiv/three-vrm, wawa-lipsync, @bolna/web-call, express (bridge), vitest (unit), Playwright (e2e, Phase 2).

**Spec:** `research/00-overview-and-hackathon-brief.md` §2 (product definition) + `research/04` §D (architecture) + `research/05` §"Recommended UI approach".

**Execution method (already chosen by user):** 3 parallel GLM-5.3-Flash subagents for Phase 1 modules (A/B/C), then a second wave (D/E/F) for integration, orchestrator (me) reviews and wires between waves. Deadline: **Oct 31, 2026**.

## Global Constraints

- TypeScript `strict: true`; `npm run typecheck` and `npm run build` must pass before any task is "done".
- **Mock mode is a first-class feature**: with no `.env` keys the full happy path (session → command → tool run → spoken/shown result) works using `MockVoiceProvider` + stub tools. Never `throw` on missing keys — degrade.
- Only MIT/Apache/BSD-licensed third-party code may be copied into `app/` (add `// adapted from <repo> (MIT)` comments). `_reference/` is never edited or imported from at runtime — copy code out.
- Transparent overlay window is created with `frame:false, transparent:true, alwaysOnTop:true, skipTaskbar:true, resizable:false` (resizable breaks transparency). macOS extra: `setAlwaysOnTop(true,'screen-saver')`.
- All user-facing strings go through `src/i18n/` (`en`, `hi`).
- Tool execution MUST go through the ACL (`checkPermission()` in the bridge) — no direct `child_process` from the renderer, ever.
- No secrets in the renderer: Bolna key lives in Electron main process env/store only; renderer gets only minted short-lived sessions.
- Ports/paths: bridge on `127.0.0.1:8765`; settings persisted to `app.getPath('userData')/mitra-settings.json`.
- Commits: conventional commits, small and frequent (`feat(persona): …`, `fix(bridge): …`).

## Review Focus (failure modes tests must pin)

1. **Missing API keys / offline** → app still runs, mock session works end-to-end (test: `MockVoiceProvider` flows to tool result with no env keys).
2. **Tool called without permission** → bridge returns 403-shaped error, overlay speaks refusal, nothing executes (test: ACL unit test).
3. **opencode not installed on judge's machine** → `run_opencode_task` degrades to simulated run with honest status message (test: PATH-lookup failure branch).
4. **Hotkey pressed mid-session** → session ends cleanly (stop audio, state → idle), second press starts fresh (test: state-machine unit test: `listening→thinking→speaking→idle` and abort paths).
5. **Transparent overlay on Windows** → window shows, doesn't steal focus from fullscreen apps, Escape dismisses (manual checklist + Playwright smoke in Phase 2 F).

## Phase 0 — Scaffold (orchestrator, done before agents launch)

### Task 0: App skeleton + frozen shared contracts

**Files:** `app/package.json`, `app/electron.vite.config.ts`, `app/tsconfig*.json`, `app/electron/main.ts` (stub), `app/electron/preload.ts` (stub), `app/src/main.tsx`, `app/src/App.tsx` (placeholder router), `app/src/shared/types.ts`, `app/src/shared/ipc.ts`, `app/src/i18n/{en,hi}.ts`, `app/tailwind.config` + `app/src/index.css`, `app/.env.example`, `app/README.md`.

**Interfaces (FROZEN — Phase 1/2 agents consume):**

```ts
// src/shared/types.ts
export type PersonaKind = 'orb' | 'avatar';
export type SessionState = 'idle' | 'listening' | 'thinking' | 'speaking' | 'error';
export type ToolName = 'notion_add_todo' | 'launch_app' | 'run_opencode_task' | 'open_url';
export interface ToolRequest { id: string; tool: ToolName; args: Record<string, unknown>; }
export interface ToolResult { id: string; ok: boolean; summary: string; data?: unknown; }
export interface Permissions { notion: boolean; launcher: boolean; terminal: boolean; browser: boolean }
export interface Settings {
  persona: PersonaKind; orbColors: { a: string; b: string }; hotkey: string;
  language: 'en' | 'hi'; permissions: Permissions;
  apps: Array<{ name: string; command: string }>;   // launcher aliases
  notion: { mock: true } | { mock: false; token: string; databaseId: string };
}
export interface TranscriptEntry { role: 'user' | 'agent' | 'system'; text: string; ts: number }
// VoiceProvider (Phase 2 D implements Bolna + Mock):
export interface VoiceProvider {
  start(opts: { language: 'en' | 'hi' }): Promise<void>;
  stop(): Promise<void>;
  onState(cb: (s: SessionState) => void): void;
  onTranscript(cb: (t: TranscriptEntry) => void): void;
  attachAudio(el: HTMLAudioElement | MediaStream): void; // feeds AnalyserNode
}
```
- IPC channels: `mitra:toggle-overlay`, `mitra:session-event`, `mitra:get-settings`, `mitra:set-settings` (in `shared/ipc.ts`).
- Bridge REST: `POST /api/session {language}` → session creds; `POST /api/tools/:name {args}` → `ToolResult`; `GET /api/health`.

- [x] Scaffold files, `npm install`, `npm run typecheck` green, initial commit.
